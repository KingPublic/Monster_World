# Audio Direction

No final audio assets currently exist in this folder. This is approved direction and a planned cue list, not ready SFX/music, a provider selection, or Roblox Asset IDs. Visual references are registered in [REFERENCE_INDEX.md](../REFERENCE_INDEX.md); filenames remain unchanged unless the user explicitly requests a rename.

## Sanctuary

Mood: warm, magical, safe, comforting, adventurous fantasy.

Possible instrumentation: light strings, flute, harp, gentle percussion, and magical ambience. These are directions, not a locked arrangement.

## Exploration

Mood: adventurous, open, curious, and uplifting.

## Guardian Chase

Triggered/escalated after theft. Mood: urgent, exciting, dangerous, and pursuit-focused. Avoid turning the game into horror; the objective is escape.
