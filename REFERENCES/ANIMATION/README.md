# Animation References

Approved V1 visual references are present. Smooth flight transitions, physical egg carrying, and readable guardian reaction/pursuit are priorities.

Flight/carry poses guide takeoff, flight, glide, banks, ascent/descent, held Shift Boost, and landing. Confirmed carry is 1 rider egg; then 1 rider + 1 dragon egg; then 1 rider + 1 egg per talon, maximum 3 eggs.

Guardian poses guide theft detection → alert/roar → chase → arrival in the thief's own safe zone → disengage → return to the original nest. Distance alone does not end aggression. Attack-pressure artwork does not approve a boss-fighting game, HP bars, or fixed attacks. The first tutorial theft/escape is on foot even though the sheet depicts a mount.

Baby idle/eating and growth transformation animation/VFX are also design needs. No dedicated production clips are established by these pose sheets; exact timings, rigs, attachments, and stage transition effects remain TBD.
